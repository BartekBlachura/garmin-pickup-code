# Pickup Code / Kod odbioru

Shows your parcel pickup code and phone number during an activity, so you can collect a parcel from a locker when you run without your phone. Works with any parcel locker that opens with a 6-digit code, for example InPost, ORLEN Paczka and Allegro One Box lockers. For InPost lockers the field can show a QR code to scan.

Pokazuje podczas aktywności kod odbioru paczki i numer telefonu, żeby móc odebrać paczkę z automatu, gdy biegasz bez telefonu. Działa z każdym automatem paczkowym otwieranym 6-cyfrowym kodem, na przykład z automatami InPost, ORLEN Paczka i Allegro One Box. Dla automatów InPost pole może pokazać kod QR do zeskanowania.
